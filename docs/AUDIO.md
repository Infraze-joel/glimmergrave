# Audio

Glimmergrave's sound is sample-based and designed in layers, with synthesis kept where it is the better tool
(element colours, tonal blooms, sweeps, growls, the generative score). Nothing here has been checked by ear:
the author of this pass could only measure. Audition everything at `http://localhost:5173/?audiodemo`.

Code: `client/src/audio/*` · samples: `client/public/assets/audio/*` · pipeline: `tools/build-audio.mjs` ·
workbench: `client/src/dev/audiodemo.ts`.

## 1. Sources and licences

(CC0 1.0)**: free for personal, educational and commercial use, no attribution required. The packs were taken
from the GitHub repositories below; for each one the licence file in the repository was opened and states CC0.
`tools/build-audio.mjs` repeats that check on every build and refuses a pack whose licence file does not say CC0.

## 2. Rebuilding the samples

```
mkdir ../audio-src && cd ../audio-src
for r in Boyquotes/kenney-rpg-audio-for-godot Boyquotes/kenney-impact-sounds-for-godot \
         Boyquotes/kenney-music-jingles-for-godot Calinou/kenney-interface-sounds Calinou/kenney-ui-audio \
         Boyquotes/kenney-sci-fi-sounds-for-godot Boyquotes/kenney-digital-audio-for-godot; do
  git clone https://github.com/$r; done        # check out the commits above for a byte-identical result
cd ../glimmergrave && node tools/build-audio.mjs ../audio-src [--verbose]
```

Needs `ffmpeg` with `libmp3lame` on the PATH (or `FFMPEG=/path/to/ffmpeg`). The build is deterministic: two runs
give byte-identical files. It rewrites `client/public/assets/audio/*.mp3`, `credits.json`,
`client/src/audio/manifest.ts` and the table above.

Per file: decode → mono → optional segment → 28 Hz high-pass (DC / rumble) → trim silence (start −46 dB, end
−52 dB relative to peak) → fade edges (1.5 ms in, 5–45 ms out; beds 60 ms) → peak-normalise to −1.5 dBFS →
MP3 (libmp3lame VBR, `-q:a 5`, beds `-q:a 7` at 22.05 kHz) → decode the result and measure it. The manifest
stores, per file, `name`, `group` (round-robin set), `cat`, `tier` (load order), `dur`, `bytes` and `gain`: the
trim that brings the file to its category's loudness target (K-weighted, loudest 100 ms; beds: whole file) —
ui −26, foley −22, impact −18, magic −20, big −16, flow −20, bed −24 LUFS. The trim is capped so that
peak × gain ≤ 0.9. To change the selection edit the `GROUPS` table in the script; to replace one sound with your
own recording put it in a source folder and point the entry at it (keep the group name).

**Format: MP3**, mono, 44.1 kHz. It is the one compressed format `decodeAudioData` accepts in Chrome, Edge,
Firefox and Safari alike; this ffmpeg can also write AAC, but AAC in M4A depends on platform decoders in
Firefox and is absent in plain Chromium builds. MP3's weakness, encoder delay at the start of a file, is
handled at run time: playback starts at the first sample above −48 dB (`leadOf` in `samples.ts`).

Shipped: **167 files, 681 802 bytes** of MP3 plus `credits.json` (8.3 kB) — 666 kB of the 900 kB budget the build
enforces since update 3 (update 3: 160 files, 650 306 bytes; update 2: 146 files, 593 917 bytes; the old files are
byte-identical each time).
Per tier: interface 89 kB, core combat 147 kB, abilities / elements / enemies 254 kB, run flow 146 kB, beds 30 kB.

## 3. Runtime

```
ui (dry) ───────────────────────────────────────────────┐
own / combat / element / big ─> burst compressor ─┐      │
ambience ─────────────────────────────────────────┼─> hurt low-pass ─> sfx (settings.sfx) ─┐
reverb send ─> room | hall convolver ─────────────┘                                         │
music tracks ─> ducking ─> hurt low-pass ─> music (settings.music) ─────────────────────────┼─> master
music reverb send ─> convolver ─> ducking                                                   │   (settings.master)
master ─> DC blocker ─> compressor ─> limiter ─> soft clip ─> output trim ─> destination
```

- **Loading.** Nothing is requested before the first user gesture (`ui:gesture`). Then `samples.ts` fetches the
  manifest's files tier by tier (interface → core combat → abilities / elements / enemies → run flow → beds),
  six at a time, and decodes them in the background. The game never waits for audio.
- **Fallback.** Every event names the sample groups its stack is built on. Until those are decoded — or if a
  file is missing — the event plays the original synthesised sound from `sfx-synth.ts`. Missing files never
  throw; one `console.warn` summarises them. (After rebuilding the samples restart a running Vite dev server
  only if file names changed.)
- **Variation.** Each voice takes the next variant of its group (round robin with a random skip), ±6 % pitch
  and ±12 % gain unless the layer is tuned material. Bone clatter, element crackles and sparks also randomise
  count, order and spacing.
- **Bursts.** Three stages: (1) a limiter per sound family (e.g. at most 4 hits per 50 ms; each extra one in the
  window is 30 % quieter; 26 sounds per 100 ms overall), (2) voice limits per pool with priority stealing — own
  hero and danger cues (3) beat the party (2), the world (1) and ambience (0); a stolen voice fades in 12 ms,
  (3) a compressor on the combat buses whose threshold sits above a single hit, then the master compressor,
  limiter and soft clipper (ceiling −2.2 dBFS).
- **Space.** Every game sound sends a little to a convolution reverb (generated impulse responses; own hero
  driest, party / enemies / big events further back), layers add more. Boss chambers crossfade to a 3.2 s hall.
  Interface sounds are dry. The score has its own reverb.
- **Hurt.** A blow to the own hero low-passes game sound and music for a moment (deeper and longer when downed).
- `initAudio()` and `audioDebug()` keep their signatures; `audioDebug()` now also reports samples, voices, live
  nodes, the piece that plays, biome and reverb.

## 6. Music

Generative step sequencer in D minor (`music.ts`), states `menu / calm / combat / elite / boss`, 1.5 s crossfades,
16-bar chord cycles with A/B sections and hashed variation. New in this pass:

- **Voices**: pads are detuned saw groups through moving low-passes, spread left / right; a formant "choir";
  leads with vibrato; bass with a filter envelope through a soft saturator; tremolo strings; glass bells.
- **Percussion and bells from samples** (kick, snare, toms, war drums, bone knocks, anvil, the Last Bell tuned
  to D), each with a synthesised fallback.
- **One piece per final boss** (`run.bossKind`, else `run.finalBoss`): Bone Regent — bell, choir, war drums,
  Phrygian bass, 132→146 bpm; Hex Matron — compound time (12 steps per bar), glass arpeggios, heartbeat kick,
  wavering melody over a major dominant, 92→108 bpm; Ossuary Stalker — bone ostinato, sub pulses, tritone
  stabs, half-bar silences, 150→164 bpm. `bossPhase` raises tempo and adds layers in all three.
- **Biome tint**: flooded = darker filter, more reverb, water-drop notes; forge = anvil hits in the beat, driven
  bass; crypt = neutral.
- **Ducking**: Resonance, boss roar / spawn / kill, the chamber-clear jingle and blows to the own hero lower
  the score smoothly; stingers fade it out first.

No CC0 music loops were found within reach, so none are blended in.

## 8. Known gaps

- **Not listened to.** Sample choice rests on file names and measurements (duration, spectrum, pitch). Musical
  fit of the jingles, the character of the sci-fi derived layers (bolts, zaps, force field) and the balance by
  ear need a human pass; the mix table makes level changes one-line edits.
- Only Chrome was tested. Firefox, Edge and Safari decode MP3, but were not run here.
- No positional audio: events carry positions, the mix ignores them (only the reverb is stereo, plus the score).
- No footsteps, no projectile fly-by or impact-on-wall sounds, no separate enemy basic-attack sounds (the server
  sends no `cast` for them), no voices.
- Burn ticks and Resonance splash damage are recognised heuristically (small ember damage; hits right after a
  `resonance`), because `hit` does not say what caused it.
- Shield state is inferred from blocked hits (damage 0), boss / champion targets from `spawn` events and
  `run.bossId`.
- Ambience beds are crossfaded with themselves instead of looping seamlessly; water is synthesised (no CC0
  water recording was available).
- The reverb is a generated impulse response, not a measured room.

### 10.1 The five new enemy kinds

Each kind has a register and a gesture of its own. Spawn signatures follow the common spawn sound by 0.14 s and
have their own limiter family (`voice`, 2 per 0.2 s), so a bomber in a crowded wave still announces itself.

- **Warnings.** Bomber and reaver cues play on the `big` bus with the priority of the own hero; their limiter
  families (`fuse` 3 per 0.15 s, `burst` 3 per 0.12 s, `leap` 2 per 0.2 s) are separate from the other enemy casts;
  the ticks, the hiss and the whistle are synthesised, so no voice limit can take them away.
- **Channels.** Mend, fuse, raise and leap are remembered per enemy id. The enemy's `kill` cuts them in 12 ms
  (a reaver killed in the air does not land). The `interrupt` event (a stun or stagger broke the wind-up) does
  the same through `sfx.interrupt(id)`: mend, raise, fuse and leap stop dead, and a scheduled landing is taken
  back. A cut mend also gets a swallowed, falling choke of 0.1 s, so the stop reads as an interruption. An
  `interrupt` for an enemy that channels nothing is silent.
- **Bomber burst.** It is not scheduled with the fuse (a stun may still stop it). It answers the server's report:
  the bomber's `kill` or the hostile `aoe`, whichever comes first within 0.2 s before / 0.3 s after the fuse's end;
  the other one is then swallowed, so the burst sounds once and the common hostile blast does not play on top.
  A bomber slain earlier bursts after `BOMBER.DEATH_BLAST_DELAY`: that burst is scheduled at the kill, and the
  `aoe` that reports it is swallowed. The reaver's landing `aoe` is swallowed the same way.
- **Necromancer.** Its death plays the collapse; the minions' own `kill` events follow through the kill limiter
  (3 per 80 ms), so six minions crumble as one gesture and not as six.
- Enemy `cast` ids are matched by `hordeCast()` (`mend`, `raise`, `fuse`, `reaver_leap`, also with a prefix);
  the stalker's `leap` and all older ids still go to the boss cues.
